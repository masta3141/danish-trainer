# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Overview

"Dänisch Trainer" — an installable, offline-capable PWA for German speakers learning Danish vocabulary (the 5000 most frequent Danish words, frequency bands A1–C1). Built as a sibling of `../greek-trainer` (itself a port of `../chinese-trainer`, the HSK Trainer): same structure, same session/streak/stories logic. Look there first when adding a feature they already have, and keep shared logic in step. Comments and code are in English; **the UI is German only** (the learner's English is weak) — no English texts, glosses or translations anywhere, Gemini is told "never English".

Four tabs — **Vokabeln** (word grid, one tile per word, filled with its progress colour once practised; search, filter panel, tap mode Info / ✓ Pool / 🔥 Streak), **Karten** (free practice + Power-Streak, incl. Gemini example sentences) **Geschichten** (Gemini stories, reader with word recognition, narration, speech recognition) and **Statistiken** (ported from the HSK app: key figures, learning calendar with 📊 bars / 📈 curve, progress distribution, progress per level, text coverage, next words, stories) — plus the settings drawer. Speech output uses browser voices only (`danishVoices()` ranked by `voiceScore()`, `settings.voiceName` '' = best automatically); narration reads Danish → German (de-DE) → Danish.

Greenlandic was considered and postponed: hardly any open word data, no browser voices, weak Gemini support, and its polysynthetic words don't fit a frequency word grid.

There is **no build system, package manager, linter, or unit tests**. Plain ES5-style JavaScript (`var`, `function`, no modules) in classic `<script>` files sharing the global scope. To run locally:

```
python3 -m http.server 8000
```

**Smoke test:** `node tools/smoke-test.js` (Node 22+, Chrome/Chromium; `--show` to watch) serves the app, opens it in a throwaway headless Chrome profile, clicks through all flows and fails on any JS error, broken expectation or third-party request. **Run it after every change**; extend it when adding features.

## Files

- `index.html` — markup plus `<link>`/`<script>` tags.
- `css/app.css` — all styles; colors are tokens on `:root` with dark-mode overrides; accent `--accent` is Dannebrog red, `--lv-a1`…`--lv-c1` for level badges.
- `data/words.js` → `WORDS` (5000 words), `data/forms.json` → `{folded word form: word id}` (~33k forms, fetched on first use by `loadForms()` in js/stories.js to find words in sentences). Both generated by `tools/build-words.py` — `words.js` is a single huge line, **never Read or grep it without limiting output** (`| cut -c1-200`). Sources and licenses: `data/README.md`.
  - Word shape: `{id, l: 'A1'..'C1', w: Danish word, a: 'en'/'et' (nouns), r: forms line ("huset · huse", "går · gik · gået", "stort · store · større · størst"), e: German gloss, p: word class code, f: frequency rank, q: share of all running words in the DSL corpus per million — used for the "Textabdeckung" stat}`; empty fields are omitted. Ids = frequency rank. `r` is shown by the "Formen zeigen" button (the field was the romanization in the Greek app).
- `tools/build-words.py` — `python3 -I tools/build-words.py <lemma-30k-2017.txt> <kaikki-Danish.jsonl.gz> [out.js] [--worklist]`; download URLs are in its docstring. Levels are frequency bands (`LEVEL_SIZES` 500/500/1000/1500/1500).
  - `tools/glosses-de.tsv` — **hand-written German glosses** (`word<TAB>gloss[<TAB>display form]`) for every word; the build only keeps words that are in Wiktionary or this file. The optional display form replaces DSL lemmas learners don't use (`megen` → `meget`, `går` → `i går`). `--worklist` prints words still without a German gloss (with the English Wiktionary glosses as a hint) — needed when raising `LEVEL_SIZES`.
  - `tools/skip.tsv` — DSL lemmas left out (corpus noise, mislemmatized forms, duplicates such as `synes` next to `syne`→`synes`).
  - forms.json rules: the more frequent word (lower id) wins a clash ("kører" → køre, not the noun "kører"), except that pronoun tables never take another word's lemma; display forms with a space register no key ("går" stays with gå); nouns without a Wiktionary table get regular forms (`regular_noun_forms`); `FORM_OVERRIDES` fixes the rest (`dem` → de, `mine` → min).
- `js/*.js`, loaded in this order: `core` (levels, storage keys, settings, progress, fonts, activity, `esc`, `fold`, `levelToColor`, toast) → `i18n` (German texts, `t`/`tf`) → `gemini` (key, model detection, `callGemini`, example sentences in IndexedDB `datrain_examples_db`) → `speech` (voice ranking, `speak`/`speakAsync`, narration, speech recognition) → `session` (pool, free-practice round, pause/resume) → `streak` (Power-Streak + own SRS) → `cards` (stats strip, start screen, card) → `stories` → `vocab` → `stats` → `settings` (drawer, import/export) → `backup` (full backup) → `navigation` (tabs, `renderAll`) → `init` (must stay last).
- Sentences (examples, stories) are `{g, e}` (Danish, German); Gemini answers in `DANISH|GERMAN` lines, parsed by `parseGeminiResponse()`.
- `sw.js` — service worker, network first, cache as offline fallback. **Bump `CACHE_NAME`** when any shell file changes and keep `APP_SHELL` in sync with `index.html` (the smoke test checks this).
- `manifest.json`, `icon.svg` — PWA metadata (no PNG icons yet).

## Working with the code

- Every `js/*.js` starts with `"use strict";`. Top-level statements may only use names from the same or an earlier file; function bodies can use anything.
- Activity (`recordActivity`, `computeStreak`, `loadDailyCounts`, `dateKeyForYMD` in js/core.js) uses UTC day keys like the HSK app; the stats calendar reads them.
- `localStorage` keys are prefixed `datrain_` and versioned `_v1`. The full backup (`datrain-backup-v1`) saves every `datrain_*` key except the Gemini key/model plus the example sentences — new storage must stay covered by it.
- Progress model as in the HSK app: `progress[id] = {lvl 0..100, lr, seen}`; missing entries count as level 0. The pool is the first `settings.pool` words in id order plus/minus `poolOverrides`.
- `fold()` (js/core.js) lowercases and strips accents but **keeps å** (NFD a + U+030A) — it must match `fold()` in the build script, which produces the forms.json keys. Search ranks exact word/form > word prefix > contains (word, forms, German gloss).
- The vocab grid renders all 5000 tiles at once; `updateWordCell(id)` re-renders a single tile after a rating, `renderVocab()` everything. Grid filters live in `datrain_grid_filter_v1`.
- When adding UI text, add the key to `I18N.de` in `js/i18n.js`.
